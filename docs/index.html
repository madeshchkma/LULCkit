          Capabilities
          
One Toolkit from Raw Raster to Publication Atlas

          
Engineered with O(1)-RAM windowed streaming and strict sensor fingerprinting so multi-gigabyte satellite scenes run reliably on laptops and cloud CPUs alike.

        

      


      

        

          

            
          

          
Sensor Fingerprinting

          
Extracts CRS/WKT, GSD in meters, WGS84 bounds, COG overviews, GDAL tags, and decimated band percentiles in milliseconds.

          lulc inspect scene.tif
        


        

          

            
          

          
ML & Categorical Styling

          
Auto-routes Sentinel-2 (s2-dw), high-res RGB (rgb-oem, rgb-fast), or zero-ML pre-classified maps (categorical).

          lulc map --model auto
        


        

          

            
          

          
Bands & Spectral Indices

          
Render true/false-color NIR, agriculture, or custom 3-band RGB composites, and stream-compute NDVI, NDWI, NDBI, SAVI, and EVI.

          lulc bands --index ndvi
        


        

          

            
          

          
Print & Web Cartography

          
Full-page A4/A5/A3/Letter print sheets at 300 DPI with X/Y axes, 5 vector north arrows, ArcGIS scale bars, plus self-contained MapLibre HTML.

          lulc map --page-size a4 --html

          Deployment Options
          
Run Locally, in Your Browser, or on Cloud ZeroGPU

          
Choose the environment that fits your raster size and workflow — all sharing the same metadata, cartography, and area-reporting standards.

        

      


      

        

          Offline Workstation
          
Python CLI (lulckit / lulc)

          
Full O(1)-RAM tiled pipeline for large rasters, vector GeoJSON polygons, 300 DPI PDF/SVG maps, and batch folders.

          
    
            
  • Pretrained s2-dw, rgb-oem, and rgb-fast ML models
    • 
            
  • NDVI, NDWI, NDBI, SAVI, and EVI GeoTIFF export
    • 
            
  • Exact pyproj.Geod geodesic area for EPSG:4326
    • 
          

          
lulc map scene.tif -o ./out --vector --html
