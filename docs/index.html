Python CLI (`lulckit` / `lulc`)

Use the CLI for multi-gigabyte rasters (`O(1)` RAM tiling), PyTorch SegFormer & Sentinel-2 Dynamic World ML inference, vector GeoJSON export, PDF/SVG print export, and directory batching.

# Inspect every tag, CRS, GSD, and band statistic
lulc inspect examples/bogura_boro_2026/Bogura_Boro_Map_10m_2026.tif

# Pre-classified or ML LULC map + PDF/PNG + CSV/JSON + HTML
lulc map Bogura_Boro_Map_10m_2026.tif -o ./out/bogura \
  --title "Boro Area Mapping for Bogura - 2026" \
  --palette arcgis-crop --page-size a4 --html

# Optical RGB / Sentinel-2 ML inference + GeoJSON polygons
lulc map sentinel2.tif -o ./out/s2 --model s2-dw --vector

# Multiband composites & spectral indices
lulc bands sentinel2.tif --composite false-color-nir -o cir.png
lulc bands sentinel2.tif --index ndvi -o ndvi.tif --preview-out ndvi.png
