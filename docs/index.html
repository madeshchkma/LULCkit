          Capabilities
          
One Toolkit from Raw Raster to Publication Atlas

          
Engineered with O(1)-RAM windowed streaming and strict sensor fingerprinting so multi-gigabyte satellite scenes run reliably on laptops and cloud CPUs alike.

        

      


      

        

          

            
          

          
Sensor Fingerprinting

          
Extracts CRS/WKT, GSD in meters, WGS84 bounds, COG overviews, GDAL tags, and decimated band percentiles in milliseconds.

          lulc inspect scene.tif
        


        

          

            
          

          
ML & Categorical Styling

          
Auto-routes Sentinel-2 (s2-dw), high-res RGB (rgb-oem, rgb-fast, or custom HF AutoModelForSemanticSegmentation via --hf-model) with --tta & --sieve-size, or zero-ML COGs (categorical).

          lulc map --model auto --tta --sieve-size 16
        


        

          

            
          

          
Bands, COGs & Spectral Indices

          
Export multi-band subset COGs, visual 8-bit RGB COGs, stack Sentinel-2/Landsat folders, and compute NDVI, NDWI, MNDWI, NDBI, SAVI, EVI, and NBR.

          lulc bands --index mndwi
        


        

          

            
          

          
Print & Web Cartography

          
Full-page A4/A5/A3/Letter print sheets at 300 DPI with X/Y axes, 5 vector north arrows, ArcGIS scale bars, plus self-contained MapLibre HTML.

          lulc map --page-size a4 --html

          Frequently Asked Questions
          
Common Questions About LULCkit

        

      

      

        

          Does Browser GeoTIFF Studio upload my TIFF files to a server?
          
No. Browser GeoTIFF Studio runs 100% locally inside your web browser using geotiff.js, proj4, HTML5 Canvas, and MapLibre GL JS, so your raster files never leave your computer.

        

        

          What raster types and sensors does LULCkit support?
          
LULCkit auto-detects and processes 9 to 13 band Sentinel-2 scenes (Dynamic World), high-resolution RGB aerial or satellite GeoTIFFs (SegFormer-B4 OpenEarthMap, SegFormer-B0 DeepGlobe, or custom Hugging Face AutoModelForSemanticSegmentation models like UPerNet, Mask2Former, and DPT), and single-band pre-classified discrete GeoTIFFs.

        

        

          Which export formats and map layouts are included?
          
LULCkit exports Cloud-Optimized uint8 GeoTIFFs with embedded GDAL colormaps, overviews, and .aux.xml named legends, multi-band subset COGs, visual 8-bit RGB COGs, full-page A4, A5, A3, Letter, Legal, and Square print maps in PNG, PDF, or SVG at 300 DPI, interactive MapLibre GL JS HTML viewers, GeoJSON polygons, CSV area summaries, and JSON metadata reports.

        

        

          How does LULCkit calculate Land Use / Land Cover areas accurately?
          
For projected coordinate systems such as UTM, LULCkit computes exact metric pixel areas from the affine transform; for geographic WGS84 (EPSG:4326) rasters, it computes per-row ellipsoidal geodesic pixel areas using pyproj.Geod.

        

        

          When should I use the Browser Studio vs. the Python CLI or Hugging Face Space?
          
Use Browser Studio for instant private styling, spectral indices, and area calculation without installation; use the Hugging Face ZeroGPU Space for browser-based PyTorch ML inference; and use the Python CLI for multi-gigabyte O(1)-RAM rasters, vector GeoJSON polygons, PDF/SVG print export, and directory batching.
